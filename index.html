1. Общие положения

1.1. Настоящая Политика определяет порядок обработки и защиты информации, которую пользователь предоставляет при использовании расширения для браузера eVo Check.

2. Какие данные мы собираем

2.1. Расширение не собирает и не передаёт третьим лицам какие-либо персональные данные пользователя.

2.2. Единственная информация, которую обрабатывает Расширение — это ссылка на объявление, которую пользователь добровольно вводит в поле интерфейса.

2.3. Расширение не отслеживает историю посещений, не читает личную переписку, не собирает данные о банковских картах, геолокации или иные персональные данные.

3. Как обрабатываются ссылки

3.1. Все ссылки обрабатываются исключительно в момент их ввода.

3.2. Расширение открывает переданную ссылку для анализа общедоступной информации, размещённой на открытых онлайн-площадках.

3.3. Мы не собираем и не храним у себя на серверах:

  • копии объявлений;
  • данные продавцов;
  • историю запросов пользователя;
  • сами ссылки после завершения анализа.

4. Где хранятся данные

4.1. Вся обработанная информация и результаты анализа хранятся исключительно на устройстве пользователя (в локальном хранилище браузера).

4.2. Расширение не отправляет данные анализа на сторонние серверы. Исключение — сам запрос к открытому объявлению по ссылке (технически инициируется браузером для получения общедоступной информации).

4.3. Удаление Расширения или очистка данных браузера полностью удаляет всю сохранённую историю и результаты анализа.
